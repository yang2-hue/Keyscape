# 推进顺序与验收

## 01 · 交互原型（已实现，非最终美术）

单键展厅、拖动／触摸旋转、近景／重置、光照、暂停、美术参考与本地 GLB 导入。构建和浏览器验证记录在 `outputs/`。

## 02 · 程序化微缩基线（已实现，美术待验收）

art-v05 起默认入口改为分离构建的程序化场景：分离地形、礁石、石屋、弧形陶瓦、百叶窗、灯塔、码头、植物、船和鱼；统一材质与凹凸纹理，使用正交相机、软阴影和 SSAO 等后期。此后 v06–v08 补齐月湾动线（岸阶／主路／支路／塔门）与夜间扫光。

## 02.5 · 工程收口（v09）

修掉三类会反复咬人的问题：暂停／减少动态时空转渲染（改为 `frameloop` 按需）、错误边界崩一次不可恢复、深链只认一件作品。参考图转为 webp 两档，构建产物 57 MB → 2.3 MB。检查脚本从被忽略的 `work/` 收敛为受版本控制的 `scripts/verify.mjs`。

## 02.6 · 月湾产品验收（v09）

按 `docs/crescent-product-acceptance.md` 的 5 项要求出了逐项对照，材料在 `outputs/crescent-acceptance-v09/`：6 张取景截图、12 秒扫光录屏、`check.json` 断言。

结论：码头过渡（23 级、落差 0.30、最大级高 0.0167）、灯塔入口（门紧贴主路、朝岛内、塔院半径 0.17）、夜间扫光（26 秒一圈，暂停与减少动态均冻结）通过；**台地与入户通路的铺装辨识度、夜景光束强度**偏弱，等用户判定是否调整。真机性能仍未测。

## 02.7 · 收敛为单件作品（v10）

用户判定只保留月湾，其余三件不再维护。

- **删除**：`潮汐之间`（渔港）、`云门拱语`、`蓝洞来信`（早期习作）的源码、测试、参考图与产物；`ArtKey.tsx` 拆出 `studio.tsx` 后删除；`work/archive` 的历史 GLB 与 PNG 一并清掉。
- **展厅改造**：去掉作品切换、方向键、`?work=` 深链与 `01 / COLLECTION STUDIES` 之类的文案，控制条重新排布；后续（02.11）连作品名也去掉了。
- **灯塔昼夜**：灯室玻璃白天 `emissiveIntensity` 归零（此前固定 0.18，白天看着像亮着），光锥与聚光灯同样只由夜航驱动。
- **天气扩展**：`晴 / 阴 / 雨 / 雾` 四种，新增指数雾；光照、雾、背景色与雨滴联动，`weather-model.ts` 存纯数值表并有单测。水面着色器接入了场景雾，否则雾天里只有陆地变淡、海还是一片饱和的青绿。
- **按需渲染的过渡窗口改为按帧计数**：原来按墙钟 1.6 秒算，在 2 fps 的软渲染下只够三帧，天气过渡会停在半路；暂停时清空剩余窗口，保证「暂停即停帧」。

验收：`tsc` 0 错误、23 项单测、构建 1.6 MB、`pnpm verify` 21 项全过（含白天灯塔不发光、四种天气雾浓度递增、暂停后 0 帧）。

## 02.8 · 自动展览与交互（v10）

用户的要求集中在四件事：撤掉美术参考、白天灯塔必须彻底熄灭、岩壁要更精致、天气与昼夜改由系统自动切换且不提供调节，另外要更多可点的交互。

- **撤掉美术参考**：侧栏缩略图、概念图弹窗、`public/references`、`optimize-references.mjs` 与 `pnpm refs` 一并删除。
- **灯塔昼夜**：灯室球由奶油白改为深琥珀玻璃（`#4c4335`，`metalness .15`），白天 `emissiveIntensity = 0`。此前虽然 emissive 已是 0，但浅色球体在正午光下仍像亮着——这是“看着还亮”的真正原因。
- **更精致的地形**：地形网格 112² → 176²，巨石球体 16×12 → 32×20；石灰岩贴图改为平铺（地形 13×、巨石 7×）并加深凹凸；着色器里给陡壁加了竖向侵蚀纹理；顶点色按网格邻域算出“折痕”并烘焙成环境遮蔽。阴影贴图 2048² → 3072²，SSAO 半径/强度上调。
- **自动展览**：删除天气与昼夜按钮，改为 7 步循环（晴 → 阴 → 雨 → 雾 → 雾夜 → 晴夜 → 雨夜），每步 20 秒，标签只读。标签页隐藏时暂停计时。`?dwell=` 仅在 DEV 下生效，用于录制证据。
- **交互**：点灯塔——白天闪三下并让光锥加速扫过，夜里加快扫光；点小船——离开泊位绕泻湖一圈 13 秒后归位；点水面——抬升波浪并惊散鱼群（鱼在水下，只能通过水面点击到）。悬停显示手型光标。
- **按需渲染的过渡窗口**仍按帧计数；暂停时清空，保证“暂停即停帧”。

验收：`tsc` 0 错误、23 项单测、构建 1.3 MB、`pnpm verify` 24 项全过（含三个交互点、自动推进、四天气、白天不发光、暂停 0 帧）。

## 02.9 · 收口与真实感（v11）

- **删掉导入作品**：App 的导入分支、拖放、`src/model.ts`、`tests/model.test.ts` 全部移除。展厅不再接受外部文件。
- **删掉「拉近观察」**：侧栏只剩一个复位按钮。
- **五个时刻**：早上晴 / 早上雨 / 晚上晴 / 晚雾 / 晚上雨。阴天从 `weather-model.ts` 里彻底删除，不再留一个用不到的预设。
- **鱼与船不再穿模**：礁石从泻湖中部（r 0.30–0.64）移到岸边环带（r 0.54–0.66），泻湖变成真正的水域；鱼每帧做硬约束——半径 ≤ 0.42、水深 ≥ 0.16、离船 ≥ 0.17，违反就推回并转向；纵向高度夹在河床与水面之间。验收里加了三条审计：不出界、不沉底、不穿船。
- **小船交互重做**：一次点击开始漂流（26 秒一圈，持续漂），再次点击它自己回泊位停好——点两次复位。返回用 2.6 秒缓动，不会瞬移。
- **更细的渲染**：`surface()` 从同一张 256 px 画布用 Sobel 生成法线贴图，材质从 bump 换成 normalMap；地形 176² 网格上叠加只在陡坡生效的高频位移（步道与台地坡度为 0，不受影响）；阴影 4096²（软渲染 1024²），SSAO 24 samples，SoftShadows 更锐。

验收：19 项单测、`pnpm verify` 29 项、`pnpm accept:crescent` 11 项。

## 02.10 · 修穿模与抽搐（v12）

- **船穿模的两个根因**：① 停泊位在码头 T 台的边缘，船体与木板重叠；② 漂流圈（半径 0.18）绕着泻湖中心画，而码头伸到离中心仅 0.28，任何一圈都会把船头扫进平台。处理：码头缩短（`PIER_HEAD = rIn − 0.26`）、船体 1.05 → 0.85 缩放、泊位改到东北水域的**实测无碰点**（(0.09, 0.32)，朝向 2.40 rad，间隙 0.11），漂流改为泊位与另一无碰点之间的正弦往返（不再绕圈）。
- **运行时净空守卫**：每帧用船体 7 个采样点分别算“船下水量”和“到码头木板的距离”，取最小值；低于 0.05 就把目标点拉回泊位，直到整条船都离开浅滩与木板。这条守卫不依赖布局数值，改构图也不会再穿。
- **鱼的抽搐**：原来是硬夹取——越界就瞬移回边界并改朝向，下一帧又越界，来回抖。改成**软约束**：用河床梯度找“更深的方向”，只改朝向 + 每帧极小位移推回；只有极端越界（超过 0.08）才瞬移。垂直方向改为阻尼，不再逐帧跳。
- **点击命中**：船体一半在水下，点水线会被水面先吃掉。加一个随船移动的隐形点击盒（`opacity:0`，不写深度）。
- **验收**：新增 `boatClearance()` / `boatWorst()` / `scoreAt()` / `fish audit`，`pnpm verify` 29 项含“船体间隙 ≥0”“鱼不出界/不沉底/不穿船”。

## 02.11 · 去掉标题（v13）

## 02.12 · 界面整理（v14）

参照 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的 84 份品牌设计文档做了外壳整理，取舍记录在 `docs/design-system.md`。

- **令牌化**：`style.css` 顶部建立 `:root`，8 条天气/夜间规则从"3 个渐变停靠点"收成 1 个 `--paper`；背景改用 `background-color` 真正 800ms 淡入，中心高光另置 `::before` 用 `opacity` 过渡（渐变本身不可插值，原来的 `transition:background` 其实是硬切）。
- **控件簇**：删掉浮在画面右侧的 `.side-tools`，复位按钮移进页脚；暂停改为胶囊、复位改为 40px（触屏 44px）圆形，描边统一 hairline。
- **状态**：按压 `scale(.95)`、悬停只换表面色（原来会 `translateY(-1px)`）、焦点环 2px/偏移 3px 且用唯一强调色；暂停状态从 `aria-pressed` 改为 `data-paused`（标签会变，按钮不该同时报告 pressed）。
- **时刻刻度**：页脚中央五格刻度，当前一格拉长并在一个停留周期内填满，与停留计时同源（`run` 计数器保证切页回来时重新对齐）。
- **可读性**：手势提示 9px → 11px；`--ink-muted` 调到 4.88:1（雨天 4.81:1）；新增 `prefers-contrast: more` / `prefers-reduced-transparency` 回退。
- **清理**：删除 `weather-overcast` 的 5 条死规则、`.toast`、`.import-button`、`.side-tools`、`.mood-controls`、`.text-button`、`.night .night .loading` 双类名笔误。

验收：`pnpm verify` 36 项（新增控件形状、按压回弹、焦点环、刻度数量与生效格、暂停状态语义），`tsc` 0 错误。

## 03 · 单件作品的深化

月湾现在是唯一作品，后续打磨都在这一件上做：

- 美术判定项：台地与入户支路的铺装辨识度、夜景光束强度、小屋与崖沿的关系；岩壁的竖向纹理是否够、地形是否还需要更细的网格。
- 材质：岸边泡沫的破碎感、木材与涂料的粗糙度分层、透明体的排序稳定性。
- 叙事：写一份「这颗键为什么值得停留」的短说明，作为展厅文案的唯一来源（目前刻意没有解释性文字）。

验收：日／夜、四种天气下主体都清晰，透明体排序正确，暂停与静态模式舒适。

## 04 · 性能与真机

真实设备测量后引入像素比上限、阴影／折射分级与纹理压缩；雾与后期在移动端需要单独的预算。目前只有 Chrome + SwiftShader（约 3 fps）的自动化数据，不能代替真机。

验收：以选定手机和笔记本的测量结果为依据设预算，并写进 `pnpm verify` 的报告里。
