# 月湾产品验收与整改要求

日期：2026-10-25  
验收对象：当前月湾 v06 的场景布局、通行逻辑与夜间灯塔表现。  
依据：当前源码、v06 实际运行截图及用户反馈。本文件不是新一轮实机测试报告。

## 验收结论

**当前不通过场景逻辑验收。**

场景已经具备小屋、灯塔、码头、石阶和局部石板路，但这些要素尚未形成可信的空间关系。需要先解决“人在岛上怎么走、怎么进屋、怎么上船，以及灯塔怎样工作”，再继续增加装饰细节。

本结论针对场景逻辑和视觉表达，不替代构建、代码、性能或内存验收。此前构建和测试通过，不代表本文件列出的要求已满足；最终美术验收由用户决定。

## 核心设计原则

以一条完整的生活动线组织岛屿：

**船 → 码头 → 岸阶 → 岛上主路 → 两栋小屋／灯塔。**

先规划可用地面、道路、建筑入口与高差，再布置岩石、灌木和其他装饰。岛屿仍应保持 C 形岛岸围抱泻湖、留有通海开口的主题。不能通过填满泻湖或关闭开口换取用地。

## 问题与整改要求

### 1. 岛与码头缺乏合理过渡

当前虽已有九级石阶，但各级高度直接取自地形，没有作为一段楼梯统一设计。取样显示，从岛上向码头方向，前段落差过大，后段又反向抬升；摆放台阶不等于形成连续通路。

整改要求：

- 明确岸边平台、楼梯上下端平台、栈桥起点及码头平台的高度。
- 按总高差统一设计台阶数量、踏步深度和级高；接入地形，避免悬空、埋入或被岩石挡住。
- 若一段直梯过陡，使用折返或沿坡石阶，并设置中间平台。
- 栈桥应明确落在岸边平台上，有可信的支撑关系；登船位置需与泊船位置对应。

通过标准：从岸边到船边能辨认出连续、合理的步行路线；无明显断口、异常高台阶或需要跳跃的衔接。主视角与侧视角均能看清岸、阶、桥的关系。

### 2. 岛屿可用平地不足

外轮廓已扩大，但建筑、岩石与植被仍挤占有限平台。单纯加大外径或增加崖壁，不能解决居住空间和通行空间不足。

整改要求：

- 为两栋小屋预留完整地基、门前平台和连接主路的支路。
- 为灯塔预留入口平台或小院，以及连接主路的通道。
- 道路宽度、台阶尺度、门洞和建筑比例采用同一个人的尺度参照；具体比例在制作方案中说明。
- 优先扩大或重塑有效台地；必要时调整建筑位置、比例及装饰密度，保留泻湖与通海开口。

通过标准：建筑落地可信，门前有可站立空间，主路能够经过建筑；道路不依赖裸岩、陡坡或灌木丛充当可行走地面。

### 3. 小屋缺少完整入户通路

目前存在局部石板路，但在靠近房屋的范围留空，尚未建立主路、支路、门前平台与门槛之间的连续关系。

整改要求：

- 先确定每栋小屋的实际门口，再反向连接入户支路与主路。
- 处理门前高差；需要时补门阶、挡土墙或平台。
- 排除道路范围内的岩石、植被和其他障碍，避免只在地面贴一条被遮挡的路。

通过标准：从码头沿主路可以分别到达两栋小屋的门口；俯视与近景中都能追踪完整路线，路径不在门前突然消失。

### 4. 灯塔缺少入口与通路

现有主路没有明确延伸至灯塔，塔身也缺少可辨认的入口，灯塔作为有人维护的建筑尚不成立。

整改要求：

- 补齐“主路 → 灯塔平台或小院 → 塔门”的连接。
- 塔门应位于可接近的一侧，避免开向悬崖、岩石或水面。
- 表达门槛和必要的入口台阶；内部楼梯无需在本轮展开，但外部入口与塔体应合理对应。
- 平台临崖处根据风险和视觉需要设置矮墙或护栏，不能遮断通行。

通过标准：能明确指出人从哪里走到灯塔、从哪扇门进入；灯塔有合理落脚平台，不是孤立插在岩石上的装饰。

### 5. 夜间灯塔缺少明确工作表现

当前已有暖色点光源和光晕，但尚无扫海光束。现有暮色画面不足以表达用户提出的夜间灯塔效果。

整改要求：

- 夜间保留可见的灯室光源，并增加缓慢旋转、方向明确的扫海光束。
- 光束从灯室发出，方向和运动连续，不应明显穿透塔体或屋顶。
- 降低夜间环境与太阳光照，让灯塔成为视觉焦点，同时保留道路、建筑和岸线的辨识度。
- 光束可用可控的视觉近似实现；不强制采用昂贵的体积渲染，但需在实际运行中可见。
- 暂停时冻结光束旋转；减少动态模式保留静态照明，停止持续扫动。日夜切换平滑，无突兀闪烁。

通过标准：默认观察距离能辨认灯室与扫海光束；连续观看可感知缓慢旋转；夜景仍能看懂岛屿布局。亮度、速度和风格由实际截图与录屏供用户验收。

## 建议实施顺序

1. **先画布局图**：标出建筑门口、灯塔入口、泊位、主路、支路和各平台高差。
2. **搭建可通行的简化场景**：仅保留地形、建筑体块、道路、石阶和码头，先检查动线。
3. **调整岛形与建筑落地**：保证可用台地、道路净空和门前空间，再确定岩岸轮廓。
4. **补齐夜间灯塔**：加入灯室照明与扫海光束，处理暂停、减少动态和日夜切换。
5. **恢复装饰并复核**：植被、岩石和生活细节服从道路及入口，不能再次堵住通路。
6. **提供实际证据验收**：逐项对照本文件，明确完成与未完成内容。
