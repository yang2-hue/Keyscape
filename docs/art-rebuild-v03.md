# 主视角重建 v03

## 原因

用户拒绝 polish-v02：海湾变成盆地，程序化建筑与生成地形材质割裂，透明水体和水下层次缺失。功能检查通过不能代替美术效果。

## 本轮路线

1. 保留已认可的渔港参考，修正制作输入中的环形岸线；新输入输出在 outputs/aholo-revision-v02。
2. 只重建一个主体，国内站标准版、目标 30 万面、无四视图增强；旧主体原件保留。
3. 船与鱼继续独立复用，水体仍由网页实现。
4. 先检查固定主视角，再验证旋转、天气、暂停和手机布局。

## 判断画面的标准

- 村落集中在一侧，海面在另一侧舒展开，避免四周高、中间低的石盆。
- 灯塔、房屋、码头、石岸的比例与材质一致，避免不同制作风格混搭。
- 水面与水下能同时读出，厚度和浅深变化可见，透明侧面贴合底座。
- 真实浏览器截图和概念图分开标注，不用概念图代替成果。

单次生成未必能还原概念图中的摄影级细节。后续若结构仍不合格，保留结果并指出问题，不为同一个缺陷持续自动抽卡。
