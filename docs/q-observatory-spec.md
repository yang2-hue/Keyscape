## 尺度与画幅

沿用展厅「一颗键托一个世界」的约定：键帽是薄底座，世界占满整个足迹。

| 项 | 值 | 依据 |
| --- | --- | --- |
| 键身 | 2.52 × 2.40，圆角 r 0.30 | 方形 1u 键，略宽于高，便于主相机斜看 |
| 键身高度 | 0.34，倒角 0.05 | 比月面 0.22 厚，因为南侧要切出峡谷 |
| 地形顶面 | y = 0 | 所有结构以地形顶面为零点 |
| 画幅 | 3.60 × 3.36，floor −0.36 | 正交相机，桥尾与键帽前唇都要留出呼吸 |
| 主相机 | [4.4, 4.0, 5.0] | 东南 3/4，比海岸低、比月面高 |

键身不能用 `ExtrudeGeometry`（会给顶面封盖，封盖从峡谷里透出来），仍然手写侧壁 + 底板，做法照抄 `lunar-base.ts`。

## 资产拆分与可动轴

| 节点 | 类型 | 可动 | 约定 |
| --- | --- | --- | --- |
| `ObservatoryDrum` | GLB 静态 | — | 含窗洞、门框、檐口、轨道齿圈；贴图随 GLB 打包 |
| `DomeHalfA/B` | GLB | 绕起拱线铰接，0 → 62° | 原点必须在铰链轴上，不能在几何中心 |
| `DomeShutter` | GLB | 随瓣联动，先收后开 | 若实现成本高，可降级为固定窄缝，不得假装能动 |
| `TelescopeFork` | GLB | 方位 ±110° | 绕 Y 轴，原点在基墩顶面中心 |
| `TelescopeTube` | GLB | 高度 15°–72° | 绕高度轴，原点在叉臂轴心 |
| `DutyRoom` | GLB 静态 | — | 窗片单独材质 `DutyWindowGlow`，按灯光强度驱动 |
| `SpiralStair` | GLB 静态 | — | 与环廊开口对齐，踏面不叠 |
| `Bridge` | 程序化 | — | 按两端硬点生成，禁止目测摆放 |
| `Terrain` | 程序化 | — | 梯度噪声 + 峡谷剖面，封闭体 |
| `Conifers` | 程序化 / 实例 | 轻微摆动 | 风起时才有明显幅度 |
| `BridgeLamps` | 程序化 | 自动 | 黄昏与夜间点亮，不单独做点击 |

拆成 GLB 的只有鼓体、两瓣穹顶、望远镜两组、值班室、螺旋梯。桥、地形、栏杆、灯、树全部程序化——这几样在 3.6 米尺度上必须靠参数改，烘焙进 GLB 会失去调整余地。

## 交互分镜

只有三处可点，全部在场景里可发现，不恢复操作菜单。

| 点击 | 结果 | 断言 |
| --- | --- | --- |
| 穹顶任一半 | 两瓣同时开 / 合，2.6 s，缓入缓出；运动中再点忽略 | `domeOpen` 0 → > 0.85，且运动中 `busy` 为真时点击不改变目标 |
| 值班室 | 窗灯与室内灯开关，状态保持到刷新 | `dutyLamp` false → true |
| 望远镜 | 在三个预设指向间轮换（天顶 78° / 低空 22° / 东偏 40°），1.4 s | `aimIndex` 递增，镜筒角度跟到目标 ±0.5° |

细节：

- 穹顶敞开时，望远镜才允许转向；闭合状态下点击望远镜只给一次轻微「碰壁」回弹，不弹提示文字。
- 桥灯、雾、星场跟随时刻自动变化，不设手动开关。
- 暂停、`prefers-reduced-motion`、页面隐藏时：三处点击不响应，动画时间冻结；减少动态时穹顶改为瞬时到位，不做 2.6 s 过渡。
- 点击热区最小 0.12 半径，栏杆与细杆的 raycast 要走代理盒，不能让用户去点 4 mm 的铜条。

## 四个时刻

| 时刻 | 光照 | 用途 |
| --- | --- | --- |
| 薄暮 `dusk` | 西侧低角暖阳 2.6 + 冷补光 0.35，环境 0.035，星场 25%，桥灯亮 | 主视角，最接近概念图 |
| 深夜 `night` | 月光 0.9 冷白，环境 0.028，星场满亮，室内暖光为主光源 | 招牌画面 |
| 黎明 `dawn` | 东侧 1.6 冷白，低雾 0.02，星场 10% | 换气口，展示地形层次 |
| 风起 `wind` | 顶光 1.1 平光，环境 0.06，尘粒 240，树摆幅 ×2.5 | 天气变化，压掉暖光对比 |

数据形状与 `lunar-weather.ts` 一致（ambient / hemisphere / sun / fill / env / fog + 颜色 + 关键光位置），直接接入现有 `useAutoCycle` 与阻尼过渡。

## 性能预算

- 程序化几何 ≤ 60k 三角面；三组 `InstancedMesh`（碎石、草簇、栏杆立柱）。
- 三个 GLB 合计 ≤ 3 MB，单文件 ≤ 1.6 MB，贴图 1024² 打包进 GLB。
- 阴影一张 4096，视锥按场景收紧（月面的 `near 3 / far 12` 教训直接沿用）。
- 后处理沿用现有 SSAO + Bloom + Vignette，不新增 pass。

## 灰模验收清单

1. 主相机下 Q 的轮廓成立：鼓形是笔画主体，桥的内折尾巴在俯视与主视角都读得出来。
2. 桥两端分别与门廊、南侧台地硬接，无悬空、无穿插；人能沿桥走到门。
3. 穹顶开到 62° 时不与 72° 仰角的镜筒相交，间隙 ≥ 0.05。
4. 螺旋梯 12 级连续到 0.52 环廊，踏面不叠，环廊开口对准梯口。
5. 峡谷侧壁封闭，不与键身侧壁重合；桥墩落在岩体上而不是悬空。
6. 键帽只在底部露一条 0.34 高的边，不抢主体。
7. 四处材质（灰泥、铸铁、铜、暖窗）在主视角能分辨，不糊成一色。

## 未定项

- 穹顶两瓣是「对开」还是「一瓣固定、一瓣滑开」：概念图是对开，成本更高；灰模阶段先用对开验证，若开合时穿帮再降级。
- 值班室是否有室内可见的陈设：主视角只能看到窗，剖面图里的桌子书架属于加分项，不进入第一版。
- Q 与 G 的实施顺序：本文件按 Q 先做编写，用户若要先做 G 可整体后移，不影响本规格。
