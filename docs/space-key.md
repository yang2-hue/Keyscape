# SPACE / 月背温室

第二颗键，按 `docs/concepts/next-keys/README.md` 已采纳的方向实现：6.25u 空格轮廓上的一段月面，居住舱、气闸走廊与一条玻璃温室。

## 与概念图的差异

| 概念图 | 实现 | 原因 |
| --- | --- | --- |
| 深空中的地球 | 只有星场 | 概念文档已判定「月背看见地球」与设定冲突，改用星空 |
| 长条键身几乎不可见 | 保留一条薄奶油边 | 展厅里仍要读得出是「一颗键」，但压到 0.22 高、5 mm 倒角 |
| 温室约占全长三分之一 | 0.98 / 3.64 ≈ 27% | 给气闸与舱体留出可读的间距，避免玻璃和白色舱体糊成一块 |
| 温室内部绿意浓密 | 双排作物 + 攀爬线 + 吊蔓 | 程序化几何在 3.6 m 尺度上撑不起真实叶片，见「已知不足」 |

## 结构（study 坐标，X 为长轴）

- 键身：`spacebarOutline()` 圆角矩形 3.64 × 1.44，壁厚 0.22，开口壳 + 底板。**不能**用 ExtrudeGeometry：它会给顶面封盖，封盖会从火山口里透出来，变成一个惨白的椭圆盘。
- 地形：`lunarHeight(x,z)` = 低频起伏 + 主火山口（半径 0.36、深 0.17、带抬升的环脊）+ 东端小坑 + 后缘低脊 + 模块下方的平整基座。顶点色按深度压暗坑底，并叠加四邻折痕的近似 AO。
- 碎石：46 块巨石（火山口环 + 东端堆）与 320 颗卵石，`InstancedMesh` + `instanceColor`。**不要**给实例材质开 `vertexColors`——实例没有颜色属性，会整体渲染成黑色。
- 居住舱：Blender 资产 `public/models/lunar/lunar-habitat.glb`（三段壳体 + 凹缝、螺栓舱门、散热板、气瓶、桅杆、碟形天线）。窗片是独立材质 `HabitatWindowGlow`，浏览器按室内亮度驱动。
- 气闸：程序化走廊 + 两片滑门 + 门内暖光；门缝里嵌了一个不可见点击盒，否则点到的永远是后面的舱体或温室。
- 温室：半圆拱壳（自定义扫掠几何）+ 金属肋 + 纵梁 + 端墙 + 基座 + 双排苗床 + 攀爬线 + 悬吊蔓 + 三条吊灯 + 两条种植灯带。
- 太阳能板：立柱 + 横臂 + 两片带边框的板，`panels.rotation.z` 随「晨昏」预置前倾，点击可再倾 0.26 rad。
- 星空 900 点、月尘 260 点，均为几何体，会随相机视差移动。

## 四个时刻（月球没有雨）

| 时刻 | 光照 | 用途 |
| --- | --- | --- |
| 晨昏 `terminator` | 低角度暖阳（key [6.2, 3.4, 2.2]，2.35）+ 冷补光，长影 | 主视角 |
| 正午 `noon` | 近顶白昼（3.4），影短、对比强 | 看结构 |
| 微尘 `dust` | 光照降到 1.7、指数雾 0.05、尘粒 100% | 月尘天气 |
| 月夜 `night` | 无太阳，只有地照（0.085 环境光）+ 室内灯；星场满亮 | 招牌画面 |

时刻数据在 `src/lunar-weather.ts`，与海岸的 `weather-model.ts` 同形（ambient / hemisphere / sun / fill / env / fog + 颜色 + 关键光位置），所以两个世界共用同一套阻尼过渡。

## 交互

| 点击 | 结果 | 断言 |
| --- | --- | --- |
| 气闸 | 两片门滑开/闭合，门内暖光渐亮 | `lunarDoor` > 0.7 → < 0.2 |
| 温室 | 室内灯与种植灯带手动开关，覆盖当前时刻 | `lunarManual` false → true |
| 太阳能板 | 板面再倾 0.26 rad | `tilt` > 0.1 |

全部服从暂停与减少动态：`playing=false` 时点击不响应，动画时间冻结。

## Blender 资产

`scripts/blender/author-lunar-base.py`（Blender 5.4.0 Alpha，`blender -b -P`）。三段舱体带凹缝、8 颗舱门螺栓、散热板、两只气瓶、桅杆与碟形天线；贴图用与海岸同一套 `textured()` 烘焙（albedo / roughness / normal 打包进 GLB），因此浏览器里不需要节点材质。导出 26,148 三角面、1.35 MB。

**踩坑**：join 之后物体会继承第一个物体的原点，直接 `location=(0,0,0)` 会让模型整体偏移 —— 必须先把游标放回原点再 `origin_set(type='ORIGIN_CURSOR')`。另外 5.4 没有 `SMOOTH_BY_ANGLE` 修改器，用 `bpy.ops.object.shade_smooth_by_angle(angle=...)`。

## 已知不足

1. **植物是团块**：三个二十面体拼一簇，远看是「绿丘」，近看没有叶片。下一步应该做叶片卡片（4–6 张 alpha 面片 + 法线朝外的随机朝向），或者直接在 Blender 里散叶并导出一组三株。
2. **玻璃没有真正的折射**：软件渲染下用普通透明材质，只有真机才走 `MeshPhysicalMaterial` 的 transmission。所以本机截图里温室玻璃偏「塑料膜」。
3. **月壤缺少宏观起伏**：除了火山口与后脊，中段几乎是平的，参考图里那种起伏的月海质感还没做出来。
4. **温室端墙是暗的**：端墙用了玻璃，但内外亮度差大，夜里读成一块黑板，需要加框与室内可见的桁架。
5. **性能未测真机**：8.6 MB 产物（GLB 共 7.3 MB），桌面独显没问题，移动端首屏与显存占用需要实测。
