# SPACE / 月背温室

第二颗键，按 `docs/concepts/next-keys/README.md` 已采纳的方向实现：6.25u 空格轮廓上的一段月面，居住舱、气闸走廊与一条玻璃温室。

## 与概念图的差异

| 概念图 | 实现 | 原因 |
| --- | --- | --- |
| 深空中的地球 | 只有星场 | 概念文档已判定「月背看见地球」与设定冲突，改用星空 |
| 长条键身几乎不可见 | 保留一条薄奶油边 | 展厅里仍要读得出是「一颗键」，但压到 0.22 高、5 mm 倒角 |
| 温室约占全长三分之一 | 0.98 / 3.64 ≈ 27% | 给气闸与舱体留出可读的间距，避免玻璃和白色舱体糊成一块 |
| 温室内部绿意浓密 | 双排作物 + 攀爬线 + 吊蔓 | 程序化几何在 3.6 m 尺度上撑不起真实叶片，见「已知不足」 |

## 结构（study 坐标，X 为长轴）

- 键身：`spacebarOutline()` 圆角矩形 3.64 × 1.44，壁厚 0.22，开口壳 + 底板。**不能**用 ExtrudeGeometry：它会给顶面封盖，封盖会从火山口里透出来，变成一个惨白的椭圆盘。
- 地形：`lunarHeight(x,z)` = 低频起伏 + **五个撞击坑**（`CRATERS`：主坑 r 0.36/d 0.16、东端副坑，另加三颗卫星坑）+ 后缘低脊 + 模块下方的平整基座 + 三层**梯度噪声**颗粒（仅在基座之外生效）。噪声必须是梯度噪声而非值噪声：值噪声的等值线跟着格子走，在大平面掠射光下会显出规则的对角线。
- 撞击坑剖面：平底（d<0.34）→ 陡壁 → **窄而高的环脊**（`exp(-(d-1.05)²/0.011)`，脊高 0.5×深度）→ 喷出毯（到 1.95r 淡出）。脊的高度与半径随方位角轻微摆动（±8%），坑壁上有低角度、低数量的滑塌沟（`sin(11θ)`，只在 d≈0.76 附近）。**坑内不放巨石**，只留 5.5 mm 以下的细砾——清空到一颗不剩会让坑底读成铸模。
- 碎石：46 块巨石（火山口环 + 东端堆）+ **5 200 颗碎砾与 320 块土坷垃**，全部 `InstancedMesh` + `instanceColor`。碎砾是「土壤感」的主要来源——法线贴图没有轮廓也没有接触阴影，只有几何能给出这两样。**不要**给实例材质开 `vertexColors`——实例没有颜色属性，会整体渲染成黑色。
- 居住舱：Blender 资产 `public/models/lunar/lunar-habitat.glb`（三段壳体 + 凹缝、螺栓舱门、散热板、气瓶、桅杆、碟形天线）。窗片是独立材质 `HabitatWindowGlow`，浏览器按室内亮度驱动。
- 气闸：程序化走廊 + 两片滑门 + 门内暖光；门缝里嵌了一个不可见点击盒，否则点到的永远是后面的舱体或温室。
- 温室：半圆拱壳（自定义扫掠几何）+ 金属肋 + 纵梁 + 端墙 + 基座 + 双排苗床 + 攀爬线 + 悬吊蔓 + 两条种植灯带。作物是 Blender 资产 `lunar-crops.glb`，三种（叶球 / 高秆 / 香草）× 叶与茎两条，按行实例化，约 80 株 6 个 draw call。
- 太阳能板：混凝土基座 + 0.26 高的立柱 + 横臂 + 两片带边框的板（总高 0.29），站在基座前的平台上。**不要做平铺在地的板**：在这个尺度上它就是一块深蓝色的水洼；立起来才有轮廓和投影。材质也别用高 metalness——暗场里 .7 的金属度几乎没有漫反射，整块板会变成一个黑洞。
- 星空 12 000 点（50% 拉进银河带）与月尘 460 点，都是**屏幕像素尺寸**的自定义着色器。`PointsMaterial` 在本场景完全不可用：`sizeAttenuation` 只在透视相机下生效，正交相机里一颗 `size: 0.028` 的星星就是 0.028 像素——星空与月尘此前一直是「写了但一个像素都不显示」。星场随相机平移（天空没有视差），月尘贴近地面漂移。

## 四个时刻（月球没有雨）

| 时刻 | 光照 | 用途 |
| --- | --- | --- |
| 晨昏 `terminator` | 低角度暖阳（key [6.6, 2.35, 2.3]，4.2）+ 冷补光，长影 | 主视角 |
| 正午 `noon` | 高白昼（key [3.6, 6.0, 2.6]，3.5），环境光压到 0.032，靠接触阴影读颗粒 | 看结构 |
| 微尘 `dust` | 光照降到 1.7、指数雾 0.05、尘粒 100% | 月尘天气 |
| 月夜 `night` | 无太阳，只有地照（0.038 环境光）+ 室内灯；星场满亮 | 招牌画面 |

**环境光是这四个时刻里最难调的一项**：一开始每个时刻都给了 0.08–0.2 的 ambient/fill/env，结果石头底下没有阴影、月壤读成塑料。现在晨昏与正午都压到 0.03–0.04，让单一光源的接触阴影去交代颗粒。

**阴影视锥必须收紧**：`near .5 / far 22` 把 4096 的深度精度几乎全花在空处，17° 的掠射太阳把剩下那点精度变成地面上一道道平行的对角条纹（当时误以为是贴图或噪声，用 DEV 开关逐项关掉才定位）。改成 `near 3 / far 12` 后，`bias -0.0001` + `normalBias .006` 就够用——**不要靠加大 normalBias 硬压**，0.03 的正常偏移会把 3 mm 碎砾的接触阴影整个抬掉。

时刻数据在 `src/lunar-weather.ts`，与海岸的 `weather-model.ts` 同形（ambient / hemisphere / sun / fill / env / fog + 颜色 + 关键光位置），所以两个世界共用同一套阻尼过渡。

## Blender 资产

三个脚本，都用 `blender -b -P` 跑：

| 脚本 | 产出 | 规模 |
| --- | --- | --- |
| `author-lunar-base.py` | `lunar-habitat.glb` | 26,148 面 / 1.35 MB |
| `author-lunar-crops.py` | `lunar-crops.glb`（3 种作物 × 叶/茎） | 1,998 面 / 52 KB |
| `bake-lunar-regolith.py` | 三张 1024² 月壤贴图 | 1.3 MB |

舱体三段带凹缝、8 颗舱门螺栓、散热板、两只气瓶、桅杆与碟形天线；贴图用与海岸同一套 `textured()` 烘焙（albedo / roughness / normal 打包进 GLB），因此浏览器里不需要节点材质。

作物的叶片是**真实几何**：4 列 × 7 段、V 形横截面、沿长度下垂的带状面。不用 alpha 卡片——叶片在这个尺寸下只有轮廓能读，而卡片的轮廓是一条边对光的矩形，转到侧面就消失。

**踩坑**：join 之后物体会继承第一个物体的原点，直接 `location=(0,0,0)` 会让模型整体偏移 —— 必须先把游标放回原点再 `origin_set(type='ORIGIN_CURSOR')`。另外 5.4 没有 `SMOOTH_BY_ANGLE` 修改器，用 `bpy.ops.object.shade_smooth_by_angle(angle=...)`。

## 月壤管线（Blender + numpy）

`scripts/blender/bake-lunar-regolith.py` 用 `blender -b -P` 跑 numpy，生成一套 1024² **可无缝平铺**的高度场，再从同一个场推导三张图：

| 图 | 内容 |
| --- | --- |
| `regolith-albedo.png` | 基础灰 + 极低幅度的斑驳；碎砾只做 ±3% 的明度差 |
| `regolith-normal.png` | 高度场的中心差分；砾石是「平顶 + 近垂直壁」的剖面，坑是碗 + 环脊 |
| `regolith-rough.png` | 0.80–1.0，砾石顶稍滑 |

四个必须记住的点：

1. **周期性格子**：所有 octave 的周期都整除 1024，所以贴图天然无缝，不需要镜像平铺，也就没有镜像对称的尴尬。
2. **砾石轮廓要破**：`1-d²` 的圆顶在任何法线强度下都像气泡。改成 `(1-d)^0.42` 并在轮廓上乘一层高频噪声，才有「碎」的边。
3. **颗粒幅度要能活过归一化**：高度场最后会归一化到 0..1，颗粒若只有 3% 的幅度，法线图就是一张平的蓝纸——第一版正是这样。
4. **平铺次数决定一切**：2.5×1 时砾石只有 4–6 px，看起来还是平的；3.4×1.36 是当前值。

材质分工：贴图给颜色与颗粒，材质 `color` 给整体明度（`#b9babb`），顶点色给宏观斑驳（近白色，只当乘数）。三者混在一起就会变成「贴了一张泥地照片的板子」。

## 已知不足

1. **作物仍偏「灌木」**：叶球是 15 片弧形叶，近看能读出叶片，但没有叶脉与真实品种的形态；高秆作物的荚也只是弯片。要更进一步需要在 Blender 里做 3–4 个真实品种（番茄、生菜、豆），而不是三种通用形态。
2. **玻璃没有真正的折射**：软件渲染下用普通透明材质，只有真机才走 `MeshPhysicalMaterial` 的 transmission。为了不让两层面片叠加成奶白，玻璃现在是单面（`FrontSide`）+ `depthWrite: false`。
3. **月壤中段仍然偏平**：颗粒是厘米级的，米级的起伏只有火山口与后脊。参考图里那种连续起伏的月海质感还差一层低频地貌。
4. **温室端墙是暗的**：端墙用了玻璃，但内外亮度差大，夜里读成一块黑板，需要加框与室内可见的桁架。
5. **性能未测真机**：产物 8.7 MB（GLB 约 7.4 MB，贴图约 1.3 MB），另外每一帧要画 5 500 个实例的碎砾；桌面独显没问题，移动端首屏与显存占用需要实测。
