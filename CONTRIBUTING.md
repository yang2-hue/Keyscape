# Contributing

Use Node.js 24 LTS and pnpm 11.25.0. Install with `pnpm install --frozen-lockfile`,
then run `pnpm dev`. Run `pnpm test` and `pnpm build` before proposing changes.

Keep changes focused. For visuals, include before/after screenshots and the
browser/device used. Check day/night, pause, reduced motion, touch layout and
deployment under `/Keyscape/`. Software rendering does not establish real-device performance.

Follow `agent.md` and `docs/design-system.md`. Record new asset provenance and
licenses. Do not commit credentials, `.env`, `work/`, `outputs/`, dependencies or
build directories. Contributions use MIT except identified third-party assets.

Report reproducible bugs through issues. For credential exposure, avoid posting
the credential; use GitHub private vulnerability reporting if the repository offers it.
