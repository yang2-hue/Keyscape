# Keyscape

把一颗键，变成一个值得停留的世界。

当前版本是**单键数字艺术展的本地交互原型**。灯塔渔港与蓝洞两件程序化习作，用于验证旋转、近景、作品切换、水面动态及光照。它们不代表最终资产精度；`public/references/` 中的 V3 概念图是美术目标，页面内可对照查看。

## 启动

需要 Node.js 22.12+、pnpm。当前在 Windows、Node 24 / pnpm 11 上验证。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173 。`pnpm build` 执行 TypeScript 检查并产出 `dist/`；`pnpm preview` 在 4173 端口预览构建结果。安装配置仅允许 esbuild 执行其依赖构建脚本。

## 已有体验

- 鼠标拖动或单指滑动旋转；滚轮或双指缩放；近景和恢复视角。
- 两件独立作品切换；桌面可用左右方向键。
- 日光／暮色、水面／渔船／鱼群轻动态、暂停；遵从系统“减少动态效果”。
- 美术参考弹窗，支持 Escape 关闭。
- 本地 GLB 导入：点击右上角或拖入展厅。校验格式、外部资源和大小，自动居中及统一展示尺寸。文件不会上传，刷新后恢复习作。

## 结构

```text
src/App.tsx       展厅、观察操作、作品选择、导入状态
src/ArtKey.tsx    原创程序化场景、水面着色器、建筑与微动态
src/model.ts      GLB 读取、资源校验、展示归一化与资源释放
src/style.css     布局、手机适配、参考弹窗、静态模式
public/references/  已认可的单键美术参考
docs/asset-pipeline.md  首颗成品资产的制作与交付约定
docs/roadmap.md   下一阶段及验收条件
agent.md         当前项目协作规则
```

React + TypeScript + Vite + Three.js + React Three Fiber + Drei。无后端、无账号、无运行时远程字体或 HDR 依赖。环境反射在本地生成。

参考 resin-diorama-collection 的场景分层、程序化生成和轻交互思路，当前代码重新编写；未复制其源码或资产。原仓库未核实到授权许可，不将其源码直接用于发布。

## 验证与边界

`pnpm test` 检查真实 GLB 的归一化、空模型和损坏文件处理。浏览器验证记录见 `outputs/verification.json`，截图见同目录。软件渲染环境的检查不能代表真实手机帧率。

当前水体是简化的透明体积与波纹，不含真实流体、屏幕空间折射、真实天气系统；两件习作共享海床。尚未使用用户交付的正式模型，未验证复杂贴图、骨骼或压缩资产。暂不支持 Draco / KTX2 等需额外解码器的文件。GLB 自带动画暂不播放，导入后展示静态几何体。首屏 3D 库体积仍偏大，正式发布前需性能预算与真实设备测试。项目目前仅在本地运行，未发布。
